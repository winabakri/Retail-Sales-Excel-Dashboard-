# Retail Sales Analysis & Interactive Excel Dashboard

## Project Overview
Conducted exploratory data analysis (EDA) on a 3,002-record retail sales dataset using Microsoft Excel to identify customer purchasing patterns, sales trends, product performance, and agent efficiency.

## Objectives
- Analyse customer purchasing behaviour and member versus non-member sales trends.
- Evaluate product and brand performance.
- Identify peak sales hours and agent contributions.
- Develop an interactive dashboard to support data-driven business decisions.

## Tools & Techniques
- Microsoft Excel
- Data Cleaning and Transformation
- Exploratory Data Analysis (EDA)
- PivotTables and PivotCharts
- Slicers and Interactive Dashboard Design
- KPI Monitoring and Data Visualization

## Key Deliverables
- Cleaned and transformed retail sales data.
- Analysed customer behaviour, sales performance, and operational trends.
- Developed an interactive Excel dashboard to monitor key sales metrics and performance indicators.

## Business Value
Provided data-driven insights into customer purchasing patterns, product performance, and sales operations to support business performance monitoring and decision-making.
